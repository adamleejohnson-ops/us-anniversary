# Us ❤️
A private anniversary story/PWA made for Hope.

## Put it on GitHub Pages
1. Create a new GitHub repository (for example `us`).
2. Upload **everything in this folder** to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. Wait a minute or two for GitHub Pages to publish the site.

## Add to iPhone Home Screen
1. Open the published site in Safari.
2. Tap **Share**.
3. Tap **Add to Home Screen**.
4. The app will appear as **Us ❤️** with your photo as its icon.

## Notes
- Progress is stored on the phone using localStorage.
- It works as a standalone PWA and has basic offline caching after first load.
- The videos were compressed for GitHub/mobile use.
- To change wording/questions later, edit `app.js`.
